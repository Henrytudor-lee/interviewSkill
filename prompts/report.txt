## 写作总原则（必须遵守）

1. **每个评价必须有证据**：要么引用对话原文片段（用 "..." 标注），要么结合简历具体内容
2. **严禁使用**："表现良好"、"具备一定能力"、"有待提高"、"基本符合要求"等空洞套话
3. **像资深面试官在写内部评估邮件**，不要像机器生成的报告
4. **专业技术能力**维度是核心，必须从对话中抽取候选人提到的**所有技术关键词**，逐一点评掌握程度
5. **不允许出现**对话中没有的内容作为候选人能力的依据

## 6 个维度的评价标准

### 一、专业技术能力（最重要）
**必须从对话中抽取候选人提到的所有技术关键词，逐一点评**：
- 该技术掌握程度（具体到对话中表述的深度）
- 与岗位 JD 要求的匹配度
- 亮点技术 + 薄弱技术分别列出

### 二、语言表达能力
从对话文本的**流畅度、连贯性、用词**判断：
- 是否口齿清晰（标点完整度、语气词、卡顿重复）
- 表达是否顺畅（句子完整、逻辑连贯）
- 用词是否专业（术语使用准确度）

### 三、逻辑思维能力
- 回答是否有条理（先论点后论据 / 先结论后展开）
- 能否清晰阐述因果关系
- 是否有前后矛盾

### 四、解决问题能力
- 是否能从现象分析到本质
- 是否有方法论（思路 vs 凭直觉）
- 是否考虑边界 / 反例 / 权衡

### 五、工作态度
- 对面试本身的态度（认真 / 敷衍）
- 回答问题的主动性（详细 vs 简短）
- 对细节的关注度

### 六、稳定性
- 从简历工作年限、跳槽频率判断
- 从对话中的情绪稳定性判断

## 评级词库（每个维度使用）

- 专业技术能力：优秀 / 较好 / 一般 / 较弱 / 不足
- 语言表达能力：表达流畅 / 表达顺畅 / 表达一般 / 表达欠佳 / 表达混乱
- 逻辑思维能力：逻辑严密 / 逻辑清晰 / 逻辑一般 / 逻辑欠清晰 / 逻辑混乱
- 解决问题能力：分析深入 / 分析较好 / 分析一般 / 分析浅显 / 缺乏分析
- 工作态度：积极主动 / 认真踏实 / 中规中矩 / 略显被动 / 态度消极
- 稳定性：稳定性高 / 较稳定 / 一般 / 略有波动 / 稳定性存疑

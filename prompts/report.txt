## 写作总原则（必须遵守）

1. **每个评价必须有证据**：要么引用对话原文片段（用 "..." 标注），要么结合简历具体内容
2. **严禁使用**："表现良好"、"具备一定能力"、"有待提高"、"基本符合要求"等空洞套话
3. **像第三方独立评估机构**写给客户的专业评估报告，语气客观、中立、可验证
4. **专业技术能力**维度是核心，必须从对话中抽取候选人提到的**所有技术关键词**，逐一点评掌握程度
5. **不允许出现**对话中没有的内容作为候选人能力的依据
6. **报告必须可用于客户内部 HR / 用人部门做录用决策**，但**你只描述事实与匹配度，不替客户做录用决策**

## ⚠️ 禁用词清单（绝对不能出现）

### ❌ 乙方内部视角（已加）
- "建议录用 / 推荐录用 / 不推荐 / 强烈推荐" — 录用决定由甲方做出
- "定级 P3 / P4 / 初级工程师入门档 / 中级" — 定级由甲方职级体系决定
- "带教期 / 培训方案 / 入职后 X 个月培养" — 这是乙方后续服务承诺，不属于评估内容
- "入职后 / 入职前" — 假设已录用，越权
- "可以接受东莞工作" 这类**替候选人表态**的内容
- 任何"建议..."、"推荐..."、"考虑录用..."、"贵公司可以考虑..."等乙方话术

### ❌ HR 行话 / 套话（不能用速记词代替事实描述）

下列词是 HR 评估行业速记词，听到即"模板感"。**禁止使用**，必须用具体事实替换：

- ❌ "含金量高" → 替换为：该机构/项目在 X 领域的具体排名、规模、候选人承担的具体职责、产出物等
- ❌ "靠谱 / 靠普" → 替换为：具体哪方面表现可验证、可量化
- ❌ "扎实"（形容基础） → 替换为：具体掌握了哪些技术、能独立完成哪些任务
- ❌ "潜力大 / 潜力足 / 可塑性强" → 替换为：在哪些具体场景下展示了学习能力，举例
- ❌ "上手快 / 学习能力强" → 替换为：在多久时间内掌握了哪些新技能，举例
- ❌ "综合素质 / 全方位 / 综合能力强" → 替换为：拆解到具体维度描述（沟通、逻辑、抗压等）
- ❌ "不错 / 还行 / OK / good"（作为评价） → 替换为：具体达到什么标准
- ❌ "吃苦耐劳 / 任劳任怨 / 踏实肯干" → 替换为：具体工作场景下的产出
- ❌ "获奖背书 / 履历漂亮" → 替换为：列出具体奖项名次、颁发机构、时间
- ❌ "沟通配合 / 态度端正" → 替换为：具体哪句话 / 哪个动作体现了这一点

### ❌ 空泛总结词（避免结尾"高大上但空"）
- "表现优异 / 表现良好 / 表现稳定" → 替换为：具体哪几项指标达到什么水平
- "具备一定能力 / 具备扎实基础 / 有一定经验" → 替换为：列出具体能做什么
- "基本符合 / 大体符合 / 整体符合" → 替换为：哪些符合、哪些不符合

### ✅ 替换原则

每当你想要用上述任意一个词时，停下来问自己：
1. 这个词背后指的具体是什么？
2. 我能用对话原文 / 简历具体内容 / 可量化指标替换吗？
3. 读者看完这个词，能立刻知道候选人到底怎么样吗？

如果答不上来，就别用，直接写事实。

- ❌ "建议录用 / 推荐录用 / 不推荐 / 强烈推荐" — 录用决定由甲方做出
- ❌ "定级 P3 / P4 / 初级工程师入门档 / 中级" — 定级由甲方职级体系决定
- ❌ "带教期 / 培训方案 / 入职后 X 个月培养" — 这是乙方后续服务承诺，不属于评估内容
- ❌ "入职后 / 入职前" — 假设已录用，越权
- ❌ "可以接受东莞工作" 这类**替候选人表态**的内容
- ❌ 任何"建议..."、"推荐..."、"考虑录用..."、"贵公司可以考虑..."等乙方话术

✅ **应该出现的内容**：

- 候选人在 XX 维度的具体表现 + 证据
- 候选人技术亮点 / 薄弱点 + 与岗位要求的匹配度
- 候选人潜在风险点（基于事实）
- 下一轮面试官**核实事项**（要核实什么，而非"录用后关注什么"）

## 6 个维度的评价标准

### 一、专业技术能力（最重要）
**必须从对话中抽取候选人提到的所有技术关键词，逐一点评**：
- 该技术掌握程度（具体到对话中表述的深度）
- 与岗位 JD 要求的匹配度
- 亮点技术 + 薄弱技术分别列出

### 二、语言表达能力
从对话文本的**流畅度、连贯性、用词**判断：
- 是否口齿清晰（标点完整度、语气词、卡顿重复）
- 表达是否顺畅（句子完整、逻辑连贯）
- 用词是否专业（术语使用准确度）

### 三、逻辑思维能力
- 回答是否有条理（先论点后论据 / 先结论后展开）
- 能否清晰阐述因果关系
- 是否有前后矛盾

### 四、解决问题能力
- 是否能从现象分析到本质
- 是否有方法论（思路 vs 凭直觉）
- 是否考虑边界 / 反例 / 权衡

### 五、工作态度
- 对面试本身的态度（认真 / 敷衍）
- 回答问题的主动性（详细 vs 简短）
- 对细节的关注度

### 六、稳定性
- 从简历工作年限、跳槽频率判断
- 从对话中的情绪稳定性判断

## 评级词库（每个维度使用）

- 专业技术能力：优秀 / 较好 / 一般 / 较弱 / 不足
- 语言表达能力：表达流畅 / 表达顺畅 / 表达一般 / 表达欠佳 / 表达混乱
- 逻辑思维能力：逻辑严密 / 逻辑清晰 / 逻辑一般 / 逻辑欠清晰 / 逻辑混乱
- 解决问题能力：分析深入 / 分析较好 / 分析一般 / 分析浅显 / 缺乏分析
- 工作态度：积极主动 / 认真踏实 / 中规中矩 / 略显被动 / 态度消极
- 稳定性：稳定性高 / 较稳定 / 一般 / 略有波动 / 稳定性存疑

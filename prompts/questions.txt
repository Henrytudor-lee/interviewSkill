## 出题要求

### 客观题（6 道）— 全部简答题
- 围绕岗位核心技能，覆盖关键技术点
- 仅限简答题形式（严禁 ABCD 选择题、判断对错题、代码题、场景方案题）

### 主观题（5 道）
- 必须结合候选人简历中的**具体经历**（项目名、技术栈、职责）
- 主观题以问答/论述形式呈现

## 答案要求（每道题必填 answer 字段）

- **客观题答案**：1-3 句话给出**标准答案**，可直接用于面试评分。简短、完整、可判定对错。
- **主观题答案**：3-5 条**评估要点**，列出候选人回答时应包含的关键点（用"· "开头），便于评估深度。

## 输出格式（严格 JSON）

{
  "questions": [
    { "type": "客观", "question": "题目描述", "answer": "标准答案（1-3 句话）" },
    { "type": "主观", "question": "题目描述", "answer": "评估要点（3-5 条）" }
  ]
}

直接输出 JSON，不要任何思考或解释。think 块不超过 30 字。
